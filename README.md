# 西安 · 一日行程

给对象（和同行的人）用的西安一日行程规划页：勾选想去的景点和饭店，自动生成一条顺路的时间轴——几点到、停留多久、怎么过去、这段花多少、累计花多少、累计有多累，最后给出总预算和总疲劳。

纯静态页面：零依赖、零构建、无 CDN、无后端，双击 `index.html` 就能用（`file://`）。

> **离线口径（v1.3）：「离线核心 + 联网增强」**——时间轴、预算、复制、PNG 导出等核心功能离线可用；地图瓦片（OpenStreetMap）与高德换乘属于联网增强，离线/失败时自动降级并明确提示，不声称全站离线。

## 打开方式

- **方式一（推荐）**：直接双击 `index.html`，用浏览器打开。
- **方式二**：在 `xian-trip-planner/` 目录起一个本地静态服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

- **手机打开（推荐）**：手机和电脑连同一 Wi-Fi，在电脑上执行 `python -m http.server 8080 --bind 0.0.0.0`，手机浏览器访问 `http://<电脑的局域网 IP>:8080`；或把整个目录部署到任意静态托管（如 GitHub Pages）。
- **不建议**把文件夹拷到手机上直接双击 `index.html`：iOS/Android 对 `file://` 下的 localStorage、脚本与下载限制很多，行为不可靠。

## 怎么用

1. 在「出发设置」里选起点（兴庆校区 / 创新港 / 自定义点位）、日期、起止时间、人数、预算档位。
2. 在「选地点」里勾选想去的地方（默认已选 4 个：兴庆校区、创新港、秦豫肉夹馍、天下第一面），可以按分类/区域筛选后「全选当前筛选」。
3. 点「一键生成行程」看时间轴；点「更省力 / 更省钱」切换方案偏好，点「重新生成」换一种顺路顺序。
4. 满意后「复制文字行程」发微信，或「导出 PNG 图片」保存。

> 规则说明：闭馆日或营业时段排不进去的地点会**跳过**——不进时间轴、不计门票/里程/疲劳，并在提示区写明原因；到达早于开门会等待开门，但离开超过闭馆就跳过。行程超过 24:00 时，时间显示为「次日 HH:MM」。

## 加地点：只改 data.js

在 `data.js` 的 `PLACES` 数组里追加一条即可：

```js
{
  id: 'your-id',                       // 唯一英文 id
  name: '地点名称',
  category: 'sight',                   // sight 景点 / food 饭店 / campus 校园地标 / hub 交通集散
  area: '碑林区',                       // 区域（自动出现在区域筛选里）
  address: '地址（可写「约」）',
  lat: 34.245, lng: 108.983,           // 坐标（不确定就写约值）
  open: '09:00', close: '18:00',       // 营业时间（全天可用 '00:00'–'23:59'）
  visitMin: 60,                        // 建议停留分钟
  cost: 0,                             // 门票/人均（元，免费 0）
  fatigue: 2,                          // 劳累指数 1–5
  tags: ['标签'],
  intro: '一句话简介',
  dataNote: '坐标/价格为约值，2026-10 整理',
  closedDays: [1]                      // 可选：固定闭馆日，0=周日 … 1=周一
}
```

`category` 决定它算门票还是餐饮（food 计入「餐饮」，其他计入「门票」），也决定默认出现在哪个分类 tab。

## 地图与每段交通方式（v1.2）

- **地图**：结果区上方是行程地图，Leaflet 1.9.4 已本地打包在 `vendor/leaflet/`（运行时不用 CDN）。起点标「起」，各站按顺序标 1、2、3…；折线颜色 = 出行方式：**步行绿 / 公交蓝 / 地铁橙 / 打车红**；点 marker 可看站名、到离时间、方式、该段费用；自动缩放到整条路线。
- **地图需要联网**：底图瓦片来自 OpenStreetMap（tile.openstreetmap.org，版权 <https://www.openstreetmap.org/copyright>）。断网/访问不到时会提示「地图瓦片需联网，行程仍可用」，时间轴、预算、复制、导出照常；Leaflet 本身是本地文件，`file://` 双击也能打开页面。
- **离线模式开关**：设置区「离线模式（关闭地图/换乘请求）」勾选后不创建瓦片图层、不请求高德，地图区显示「离线模式：地图与换乘已关闭」；开关状态存 `localStorage`，刷新后保留。默认关闭（即联网增强开启）。
- **每段自选方式**：时间轴第 2 站起每段有下拉（推荐 / 步行 / 公交 / 地铁 / 打车），改选后立即重算该段耗时、费用、疲劳、全表累计、汇总和地图折线颜色，不刷新页面；单段超过 2 km 时「步行」选项禁用（双校区等长距离强制地铁/打车）。
- **推荐理由**：每段标「推荐：地铁 / 公交 / 打车 / 步行」，并给一句实算理由（对比其他方式的时间与费用，来自 `recommendLeg()`，不是写死文案）。
- Node 里也能测方式覆盖：`buildPlan(ids, { modeOverrides: { 'xingqing->qinyu': 'taxi' } })`。

## 高德公交换乘（已配置 Key，2026-10-19）

> 换乘详情属于联网增强；离线模式开启或请求失败/超时时只保留官方深链，不影响时间轴与预算。

- **当前状态**：`app.js` 顶部已填入高德「Web 服务」Key，公交/地铁段会自动展开真实换乘（如「地铁5号线：太乙路上→创新港东下（23 站）→ 27路：创新港医院上→创业大厦下（4 站）」）。
- **停用/降级**：把 `AMAP_KEY` 置空即回到官方深链模式——步行段 `mode=walk`、公交/地铁段 `mode=bus`、打车段 `mode=car`，不展示任何编造线路号。
- **实现**：对公交/地铁段用 JSONP 调高德公交路径规划接口（`city=029`、`strategy=0`），解析第一方案的步行+公交/地铁段；懒加载 + 成功缓存 + 失败 60s 短缓存，失败/超时自动回退深链。线路名按接口原样展示，不自动补「路」、不拼造。
- **风险提示**：本项目无后端，Key 在前端代码/公开仓库中可见。请在高德控制台设置配额告警、定期轮换；如需完全不暴露 Key，可改为本地使用或加一层自己的服务端代理。也可以在浏览器控制台执行 `localStorage.setItem('xian-trip-amap-key', '你的Key')` 临时覆盖。

## 怎么改算法参数

`app.js` 顶部的 `CFG` 集中了所有参数，改完刷新页面就生效：

| 参数 | 含义 | 默认 |
|---|---|---|
| `roadFactor` | 直线距离 → 道路距离的弯曲系数 | `1.2` |
| `walkMaxKm` | 多近就步行 | `0.8` |
| `buffer` | 等车/进出站缓冲（分钟） | 步行 0 / 公交 5 / 地铁 6 / 打车 3 |
| `speed` | 各方式平均速度（km/h） | 步行 5 / 公交 20 / 地铁 35 / 打车 30 |
| `meals` | 饭点窗口 | 11:30–13:30、17:30–19:30 |
| `fatigueBands` | 疲劳分级阈值 | 0–8 轻松 / 9–15 适中 / 16–24 偏累 / >24 很累 |

出行方式的规则在 `pickMode()`：≤0.8 km 步行；>8 km 默认地铁或打车；经济档优先公交/地铁，舒适档优先打车；「更省力」优先打车，「更省钱」进一步优先 2 元公交和步行（用时间换钱，跨城段会明显更久）。

预算在 `computeBudget()`：门票（非 food）× 人数 + 餐饮（food）× 人数 + 交通（每段按「元/人 × 人数」估算，打车同样按人头估算，多人共乘时实际更便宜）；总预算由三项相加，页面上的分项与合计始终一致。所有价格展示均为约值（页面上带「约」字）。

排序在 `orderPlaces()` / `twoOpt()`：对最近邻、最远点优先、按区域聚类三种候选顺序按总里程取优，再用 2-opt 反转局部顺序减少折返；「重新生成」只在不比最优方案差 2% 以上时换一种顺路走法，不会越点越远。

## 数据说明

- 所有坐标、门票、人均价格均为**约值**，2026-10 整理，出行前请以官方渠道为准。
- 营业时间写的是大致时段；陕西历史博物馆约周一闭馆，已在数据里标注 `closedDays: [1]`，选择周一去会给出提示。
- 兵马俑等远点会在结果里提示单程耗时，建议单独安排半天。
- localStorage 只存 3 个 key：`xian-trip-prefs`（勾选/偏好）、`xian-trip-offline`（离线模式开关）、`xian-trip-amap-key`（可选的高德 Key），不含任何个人信息。

- 数据口径：只写「约」值，不做精确票价/坐标承诺；如需精确信息请以景区/学校官方发布为准。
